# 실기기 QA 체크리스트

Android 1대 + iPhone 1대를 서로 연인으로 연결해서 확인한다. 기준은 [planning.md](../product/planning.md)(동작)와 [design.md](../product/design.md)(화면 · 글 규칙), Figma "✅ 최종 화면 v2"(각 섹션 노드는 design.md 표). 화면이 Figma 와 다르면 해당 섹션 노드를 열어 비교한다.

- 서버: Firebase `kkotsin-dev`(함수 17개 · 규칙 · Hosting 배포됨). 초대 호스트 `kkotsin-dev.web.app`.
- 결과는 항목 번호마다 **통과 / 실패 / 못 해봄** + 증거(스크린샷 · 로그). 실패는 재현 단계 · 기대 · 실제를 적는다.
- 역할: 아래에서 **A = Android(곰신)**, **B = iPhone(군인)** 으로 둔다. 테마는 역할 기본값이 맞는지 보려고 일부러 이렇게 나눈다.

## 공통 규칙 (모든 화면에서 같이 본다)

| 규칙 | 기대 |
|---|---|
| 설명 문구 없음 | 화면을 설명하는 "~해요" 문장이 없다. 남는 글은 제목 · 버튼 · 라벨 · 오류 · 되돌릴 수 없는 동작 앞 한 줄 경고 · 법적 고지뿐. 입력란 placeholder 없음 |
| 버튼 이름 | 동작 이름("해제하기", "지우기"). "예/아니요" 없음 |
| 확인 창 | 버튼 3개까지, 위험한 동작엔 항상 "취소". 정보 알림은 토스트 |
| 하트 | **보고싶어 버튼에만**. 다른 곳은 우표 · 소인 · 봉투 · 군번줄 |
| 기울기 · 테이프 | 보여 주기만 하는 물건(홈 태그 · 폴라로이드 · 추억 페이지 · 책 표지)에만. 편지 쓰기 · 읽기 · 입력란 · 목록 · 봉투 · 시트 · 버튼은 반듯 |
| 글꼴 | 제목 · D-day 숫자는 손글씨, 본문은 고딕 |
| 아이콘 | Phosphor Regular |
| 테마 토큰 | 바탕 · 글자 · 버튼 · 봉투 · 탭 바가 테마를 따른다. 하드코딩 색으로 튀는 곳이 없다 |
| 편지지는 콘텐츠 | 보낸 사람이 고른 편지지 그대로. 받는 사람 테마 · 다크 모드로 바뀌지 않는다 |
| 접근성 | 터치 영역 48dp(44pt), 글자 최소 11pt, 대비 4.5:1, 글자 200% 확대에서 잘리거나 겹치지 않음 |
| 뒤로 가기 | iOS 가장자리 스와이프 · Android 예측형 뒤로 가기 |
| 날짜 · 시간 입력 | 하루: Material 3 모달 캘린더, 기간: 기간 피커, 시간: 입력형 |
| 광고 | 캘린더 · 휴가 · 설정에만. 홈 · 편지 · 그림 · 추억에는 절대 없음. 꽃신 평생이면 숨김 |

## 1. 첫 실행 · 로그인 · 온보딩 (Figma `343:83`)

1. **스플래시**: 슬로건 "편지로 이어지는 우리 둘만의 달력" 하나.
2. **업데이트 필요 · 점검 중 게이트**: Remote Config `min_version_dev` · `maintenance_dev` 가 비어 있음 · false 라 그냥 통과해야 한다. (선택) 콘솔에서 `maintenance_dev=true` 로 바꾸면 모든 화면이 "점검 중"으로 막히고 "다시 시도"로 풀리는지, 끝나면 반드시 false 로 되돌린다.
3. **로그인 버튼**(design.md 플랫폼 규칙):
   - 순서 카카오 → Apple → Google, 같은 크기 세로 스택.
   - 카카오 #FEE500 · 말풍선 심볼 · "카카오 로그인" / Apple 검정 "Apple로 계속하기" / Google 흰 바탕 · 회색 테두리 · 컬러 G "Google로 계속하기".
   - **Apple 로그인이 Android 에도 보인다.**
4. **로그인 동작**: A 는 카카오(qa 빌드에서만 됨) · Google, B 는 Apple · 카카오 · Google 중 하나씩 실제로 끝까지. 취소하면 로그인 화면으로 돌아오고 오류 문구가 이상하지 않은지.
5. **나이 확인**: 만 14세 이상 체크가 있고, 체크 없이 진행되지 않는다.
6. **온보딩 입력**: 역할(곰신 · 군인) · 이름 · 군종 · 입대일.
   - 군종 카드에는 사실만(예: "18개월"). 설명 문장 없음.
   - 군종별 복무기간: 육군 · 해병 18, 해군 20, **공군 21**, 사회복무 21개월.
   - 입대일을 넣으면 전역일이 자동 계산(입영일 + N개월 − 1일). 전역일은 직접 고칠 수 있다.
7. **역할별 기본 테마**: 곰신 → 곰신 테마(편지지 · 말린 꽃 · 크라프트 · 로즈), 군인 → 군인 테마(군사우편 · 카키 · 스텐실 · 군번줄).
8. **입대 전 연결 유도**: 입대일이 미래면 연결을 강하게 안내하고 초대 링크 공유를 바로 띄운다.

## 2. 초대 · 연결 (planning §4 · §8, Figma `343:83`)

1. **A 가 초대 링크 보내기**: 카카오톡이 깔려 있으면 카카오 피드로 공유된다(없으면 OS 공유 시트).
   - 카톡 메시지: 봉투 이미지(800×800) · 제목 "{A 이름}님이 꽃신에 초대했어요" · 설명 "편지로 이어지는 우리 둘만의 달력" · 버튼 "초대 받기". 이름 외 개인 정보 없음.
2. **보낸 직후**: A 는 바로 홈으로 간다. 홈에 "초대 보냄 · 기다리는 중" 표시와 "링크 다시 보내기". 이 상태에서 A 는 혼자 모드로 다 쓸 수 있다.
3. **B 가 받기**:
   - 앱이 깔린 B: "초대 받기" → 앱이 열리고 수락 화면 → 연결.
   - 앱이 없는 B: "초대 받기" → **App Store** 로 간다(Android 라면 Play). PC 에서 열면 `https://kkotsin-dev.web.app/i/{token}` 웹 페이지.
   - 링크 `https://kkotsin-dev.web.app/i/{token}` 를 메모 앱 등에서 누르면 **브라우저를 거치지 않고 앱이 바로** 열린다(Android App Links · iOS Universal Links).
   - 링크를 메신저(아이메시지 등)에 붙이면 미리보기에 1200×630 이미지 · 슬로건이 뜬다.
4. **연결 완료**: A 에 푸시 알림, A 가 앱을 열면 연결 모달. 숫자 비교(SAS)나 코드 입력은 **없다**.
5. **만료 · 재사용 링크**: 링크는 한 번만 쓰이고 7일 뒤 만료. 이미 쓴 링크나 새 링크를 만든 뒤의 옛 링크를 열면 "이 초대 링크는 만료됐어요" + "내가 초대 링크 보내기".
6. **연결 뒤 동기화**: A 에서 바꾼 프로필 이름 · 입대일 · 일정이 B 에 나타난다(그 반대도).

## 3. 혼자 모드 (planning §3, 출시 조건 4)

먼저 A 혼자 상태에서(연결 전) 확인하고, 2번 연결을 한다.

1. 혼자서 홈 D-day · 전역일 · 계급이 보인다.
2. 편지를 2~3통 쓴다 → A 폰에만 쌓인다(상대 키가 없으므로).
3. 연결이 완료되면 쌓인 편지가 자동으로 전달되어 상대 편지함에 나타난다. 별도 전송 진행 화면이나 편지 도착 안내는 표시하지 않는다.
4. B 에서 그 편지들이 정상적으로 열리고 내용 · 편지지가 맞다.

## 4. 홈 (Figma `350:686`)

1. **주인공**: 손글씨 큰 D-day(전역까지). 그 아래 복무 진행 막대(Service Progress), 종이 태그 2개(현재 계급 · 다음 진급 "예정" 등).
2. **계급**: 이병 2 · 일병 6 · 상병 6개월 뒤 병장. 다음 진급일은 "예정"으로 표시(심사 · 누락이 있을 수 있어서).
3. **"오늘 온 편지" 줄**: 오늘 받은 편지가 있으면 보이고 누르면 읽기로.
4. **보고싶어 버튼(FAB)**: 하트는 여기에만. 누르면 상대에게 전달 · 알림.
5. **그날의 한 줄 카드**: 만남 일정(면회 · 휴가 · 외박)이 끝난 **다음 날** 홈 카드 + 푸시. 눌러서 한 줄(40자) + 사진 남기기.
6. **상태별 배치**: 혼자 모드 · 입대 전 · 연결됨이 각각 Figma 상태와 같은지. 불러오는 동안 스켈레톤.
7. **광고 없음.**
8. **추억 책 권유 팝업**(조건이 맞을 때만): 전역 D-30~D-8 사이 처음 연 날 한 번 · 전역일 한 번, 홈 위 가운데 팝업(표지 미리보기 + "다시 보지 않기 | 닫기"). 홈 자체는 그대로. 확인하려면 입대일을 조정해 D-30 이 되게 만들어 본다(끝나면 되돌림).

## 5. 캘린더 · 휴가 · 기념일 (Figma `354:1267`)

1. **휴가 관리 위치**: 캘린더 탭 위쪽(설정에는 없음).
2. **하나의 풀**: "남은 휴가 N일 / 전체 M일". 전체 = 정기휴가 + 받은 휴가 합. 정기휴가는 군종으로 자동(육군 · 해병 24, 해군 27, 공군 28일). "휴가 없음" 빈 상태가 없다.
3. **받은 휴가 추가**(포상 등): 출처 내역에만 쌓이고 전체에 더해진다.
4. **휴가 사용**: 일정 추가에서 "휴가"를 고르는 것 = 휴가 사용 등록. 기간을 고르면 "5일 사용 · 남은 휴가 13일" 미리보기. 출처를 고르는 단계가 **없다**. 시작 · 끝 · 주말 모두 포함해 센다.
5. **일정 종류 색 6개**: 휴가 · 외박 · 면회 · 훈련 · 당직 · 기념일이 서로 다른 색.
6. **기념일**: "매년 반복"(기본 켬). 반복 기념일 당일 09:00 알림: 제목 "오늘은 {일정 제목}", 본문 "N년째 돌아온 날"(커플 기념일은 "N주년이에요" / "오늘은 우리 기념일").
7. **다음 만남 카드**: "다음 만남 · 외박 / D-3 / 10월 24일(토) 09:00 · 1박 2일" 형태.
8. **동기화**: A 가 추가 · 수정 · 삭제한 일정이 B 에도 반영.
9. 광고는 여기엔 있어도 된다(평생 구매 후엔 사라짐).

## 6. 편지 (Figma `360:2610`)

### 6-1. 편지함
1. **밑줄 탭**, 월 머리.
2. **봉투 표시**: 봉인("새") = 안 읽은 편지 · 폴라로이드 = 그림이 든 편지 · 소인("보냄") = 내가 보낸 편지 · 우표(D-day) = 그 밖의 받은 편지.
3. **임시저장 줄**: 맨 위 "쓰던 편지 N통". 빈 상태 설명 문구 없음.

### 6-2. 쓰기
1. 쓰기 버튼 → "편지 쓰기 / 그림 그리기" 메뉴.
2. 쓰기를 열 때 쓰던 편지가 있으면 "이어 쓸까요?" 시트.
3. **편지지 10종**: 무료 로즈 줄노트 · 군사우편 · 원고지 · 크라프트 · 하늘 수채 / 평생 벚꽃 엽서 · 밤하늘 · 체크 노트 · 빈티지 타자 · 라벤더 수채. 새 편지 기본값은 로즈 줄노트. 평생 편지지는 평생 구매 전엔 잠금(누르면 평생 안내 시트).
   - 줄 · 원고지 칸 · 체크 격자 · 타자 점선 · 수채 번짐 · 꽃 · 별이 그려지고, 견본에도 무늬가 보인다.
   - 군사우편은 쓰기 화면에도 "군사우편" 박스가 있다.
4. **예약 보내기**: 날짜는 모달 캘린더, 시간은 입력형. 예약 시각 전엔 B 에서 "아직 못 열어요", 시각이 되면 열린다.
5. 보내는 중 / 보냄 / 실패 상태, 나가기 확인(임시저장).
6. 임시저장은 기기에만 있고 다른 폰 · 기기 교체로 복구되지 않는다.

### 6-3. 읽기
1. **소인**: 군인이 보낸 편지는 "군사우편", 곰신이 보낸 편지는 "꽃신 우편".
2. **편지지 그대로**: A(곰신 · 라이트)가 밤하늘로 보낸 편지를 B(군인 · 다크)에서 열어도 밤하늘 그대로. 반대로 로즈 줄노트를 다크 모드에서 열어도 밝은 종이 그대로.
3. 그림이 든 편지는 폴라로이드로 보인다.
4. "고마워" 답장 → 보내면 "고마워 보냄" 상태.

## 7. 그림 (Figma `364:3873`)

1. 아래 툴바: 붓 · 지우개 · 스티커 · 사진 · 액자 · 되돌리기 · 다시.
2. 펜 시트(굵기 · 색), 액자 시트, 스티커 분류 칩.
3. "편지에 붙이기 / 그림만 보내기", 미리보기는 폴라로이드.
4. 받은 그림: **그리는 과정이 그대로 재생**되고 끝 화면이 나온다. "그림으로 답장"은 바로 그림판.
5. 사진 넣기: 플랫폼 기본 사진 선택기.
6. 큰 화면(태블릿)에서 그림판 배치.

## 8. 추억 (Figma `366:3958`)

1. 목록: 테이프 붙은 월 "페이지"(폴라로이드 · 봉투 · 종이 태그), 위 막대 책 아이콘, 빈 달은 점선 빈 페이지, 스켈레톤.
2. 한 달 화면: 그날의 한 줄 · 사진 · 편지가 날짜순.
3. 위쪽 "그날의 한 줄" 버튼.
4. **추억 책**: 표지 2종(꽃신 편지지 · 군사우편) 중 고르기, 속지(표지 · 요약 · 한 달 · 마지막 장). 구매(5,900원)는 둘 중 한 명이 사면 둘 다. PDF 화면용 + 인쇄용.
5. 광고 없음.

## 9. 알림 · 푸시

1. 상대가 보낸 편지 · 그림 · 보고싶어 · 연결 수락 · 그날의 한 줄 · 기념일이 푸시로 온다. **앱이 꺼져 있을 때도**.
2. 알림 글은 제목 + 사실 한 줄.
3. 알림 설정 페이지에서 끈 종류는 오지 않는다.
4. iOS 에서 아무 푸시도 안 오면: Firebase 콘솔 › 프로젝트 설정 › 클라우드 메시징에 APNs 키가 있는지 먼저 본다(이번 작업에서 확인하지 않은 부분).
5. iOS 알림 확장(NSE)이 편지 첫 줄 등을 복호화해서 보여 주는지.

## 10. 위젯 (Figma `383:5321`)

Android(Glance) · iOS 둘 다.

1. 중간 D-day(태그), 중간 그림, 상대 상태, 큰 한눈에 보기, 잠금 화면 위젯, 다크 작은 위젯.
2. 계급은 "예정" 표시 규칙과 같다.
3. 그림 위젯 테두리 색은 그림을 보낸 편지의 편지지와 맞는다(벚꽃 · 크라프트 · 밤하늘).
4. 위젯에서 보내기(보고싶어 등)가 되면 상대에 전달된다.
5. 하드코딩 색 없이 테마 · 다크를 따른다.

## 11. 설정 (Figma `376:4458`)

1. **그룹 순서**: 프로필 · 우리 · 꾸미기 · 알림 › · 데이터와 보안 · 도움 · 계정 · (광고 칸). 제목 붙은 둥근 카드 그룹, 하위 화면으로 가는 줄에만 ›.
2. **휴가 관리 없음**(캘린더로 옮겨짐). **백업 · 복구 코드 없음**.
3. **꾸미기**: 꽃신 평생 · 테마(곰신 · 군인) · 화면 모드(라이트 · 다크 · 시스템). 바꾸면 즉시 전 화면 적용.
4. **알림 페이지**: 종류별 스위치.
5. **데이터와 보안 › 기기 바꾸기 · 복구**: 복구 방법 안내 + "두 폰을 모두 잃으면 되찾을 수 없다" 한 줄 + **내 기록 내보내기(ZIP)**. 내보낸 ZIP 이 열리고 편지 · 일정이 들어 있는지.
6. 광고 칸은 평생 구매 후 사라진다.

## 12. 기기 바꾸기 · 복구 (planning §4 · §5, Figma `366:3961`)

두 폰이 연결된 상태에서. 세 번째 기기(다른 폰 · 에뮬레이터 · 시뮬레이터)가 있으면 그걸 "새 폰"으로, 없으면 B 에서 앱을 지웠다가 다시 깔아서 "새 폰"으로 쓴다.

1. 새 폰에서 같은 계정으로 로그인 → **상대 폰(A)에 "새 폰 맞나요?" 알림**.
2. A 가 승인 → 새 폰이 **A 폰에서** 공유 데이터(편지 · 일정 · 휴가 · 기념일 · 프로필 · 읽음 · 사진 · 그림 원본)를 받는다. 코드 입력 · 숫자 비교 없음.
3. 복구되지 **않는** 것: 기기 설정 · 임시저장 편지 · 현재 상태.
4. 옛 폰이 켜져 있으면 "새 폰에서 로그인했어요" 알림. 거기서 막을 수 있다.
5. 24시간 안 두 번째 교체 요청: 자동 승인되지 않고, 상대 화면에 경고 + 한 번 더 확인.
6. 승인 도중 앱을 꺼도(A 쪽) 다시 켜면 이어진다.
7. 요청은 7일 뒤 만료.

## 13. 연결 해제 · 탈퇴 (맨 마지막에)

1. 연결 해제 직전 내보내기 권유, 되돌릴 수 없다는 한 줄 경고, 버튼 "해제하기" + "취소".
2. 해제 뒤 각자 자기 사본을 가진다. 보낸 편지는 받은 사람 것(받은 쪽에 남는다).
3. 탈퇴 직전 내보내기 권유. Apple 로그인 계정 탈퇴 시 Apple 토큰 폐기(함수 `deleteAccount`)가 오류 없이 끝난다.

## 14. 구매 (planning §6)

1. **꽃신 평생 7,900원**: 가격이 원화로 바르게 보인다(Test Store $99.99 가 아님).
   - Android: **prod(기본 패키지) 빌드**에서만 실제 Play 상품이 잡힌다. qa · dev 에서는 상품이 안 보이는 게 정상.
   - iOS: App Store Connect Sandbox 테스터 계정으로.
2. 구매 후: 광고 제거 · 글꼴 7종 · 평생 편지지 5종 · 펜 · 색 · 위젯 꾸미기 열림. **연결된 상대(B)에게도 함께** 열린다.
3. 앱 재설치 · 구매 복원 후에도 유지.
4. 추억 책 5,900원: 한 명이 사면 둘 다.

## 15. 테마 · 다크 · 큰 화면 (Figma `386:5350`, `429:10725`)

1. 4개 모드(곰신 · 군인 × 라이트 · 다크)로 홈 · 편지함 · 읽기 · 캘린더 · 설정 · 추억을 한 번씩 돈다. 글자가 바탕에 묻히는 곳이 없다.
2. 편지지는 4개 모드 모두 같은 색.
3. 글자 200%: 잘림 · 겹침 없음.
4. 큰 화면(태블릿 · 가로): 콘텐츠 최대 폭 600dp 가운데, 편지함 목록 | 읽기 2단, 캘린더 옆 일정 목록, Nav Rail.

## 16. 공통 상태 화면 (Figma `385:5342`)

1. 네트워크 없음: 비행기 모드로 켜면 오프라인 화면 · 다시 시도. 끈 뒤 보낸 편지는 연결되면 나간다.
2. 서버 오류 · 업데이트 필요 · 점검 중 화면 문구가 Figma 와 같다(설명 문장 없음).

## 17. 분석 (GA4)

1. Firebase 콘솔 › 애널리틱스 › 실시간(또는 DebugView)에서 이벤트가 들어온다.
2. 이벤트 종류: 화면 진입(`ViewEnter`) · 초대 링크 생성 · 수락 · 연결 · 혼자 편지 대기 · 편지 · 그림 보냄 · 구매 시작 · 완료 · 플래그 · AB 노출.
3. **사용자가 입력한 글자(편지 내용 · 이름 · 한 줄 등)가 이벤트 값에 없다.**
