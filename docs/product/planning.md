# 꽃신 기획서

2026-10-28 기획 점검(질문 35개)과 디자인 점검에서 확정한 결정을 정리한 문서다. 화면 · 디자인 시스템 기준은 [design.md](design.md)를 본다.

> 원본은 Obsidian 노트 "꽃신 기획서"(2026-10-28)였고, 이 파일이 이제 기준 문서다. 결정이 바뀌면 여기를 고친다.
>
> 지금 코드와 다른 결정이 많다(예: 서버 백업 · 복구 코드 · SAS 숫자 비교 · 휴가 출처별 차감 · 4개 테마). 코드와 이 문서가 다르면 **이 문서가 목표**이고, 코드는 아직 옮겨 가지 않은 것이다.

## 1. 한 문장

**전역까지 함께 세는 둘만의 공간.**
군 일정 계산(전역일 · 진급 · 휴가) + 편지 + 추억 책. E2EE와 손그림 리플레이는 이 약속을 받쳐 주는 근거이고, 앞에 내세우지 않는다.

- 범용 커플 앱(비트윈 · 썸원)에는 군 일정 계산이 없다.
- 더캠프는 한 방향이고 훈련소 기간에만 쓰인다. 꽃신은 복무 기간 내내 양방향이다.
- 군돌이 같은 전역일 앱은 한쪽만 쓴다. 꽃신은 두 사람의 공간이다.

## 2. 사용자

| 항목 | 결정 |
|---|---|
| 주 사용자 · 결제자 | **곰신**. 매일 열고, 결제는 대부분 곰신이 한다 |
| 군인 | 짧은 사용 시간에 몰아서 읽고 답하기 좋게 만든다. 결제할 수도 있으므로 군인 테마에서도 같은 결제 흐름을 둔다(평생 혜택은 연결된 상대도 함께) |
| 먼저 설치하는 사람 | **누구든**. 곰신은 커뮤니티 · SNS로, 군인은 앱스토어에서 "전역일 계산기"를 검색하다가 들어온다. 누가 먼저 깔든 혼자서 전역일 계산기로 바로 쓰고, 그다음 상대를 초대한다. 군인 쪽 초대 문구와 첫 화면도 같은 무게로 디자인한다 |
| 가입 나이 | **만 14세 이상**(체크로 확인). 미성년자 결제는 스토어 보호자 정책에 맡긴다 |

설치 시점과 훈련소:
- 커플은 **입영통지서(영장)가 나온 뒤, 입대 전에** 앱을 설치한다.
- 훈련소에서도 앱을 설치할 수 있다. 훈련병은 2024-09부터 **주말 · 공휴일에 하루 1시간** 휴대폰을 쓴다(소대마다 시간대가 다르고, 훈련이 있으면 취소될 수 있음).

참고(2026-10 공개 자료 조사):
- 곰신 커뮤니티: 네이버 '고무신 카페 곰신모임' 약 60만 명(나무위키 기준). 더캠프 MAU 65만 명(2023).

## 3. 생명주기

```
영장 ── 입대 전 ── 훈련소(약 5주) ── 자대 ── 전역 D-30 ── 전역 ── 보관 모드
 설치    연결 유도    주말에 연결 가능    일상 사용   추억 책 권유      완결     기록 중심 홈
```

- **영장 → 입대 전**: 커플이 앱을 설치하는 시점이다. 입대일이 아직 오지 않았으면 "입대 전에 같이 연결해 두세요"를 강하게 안내하고, 초대 링크 공유를 바로 띄운다. 대부분의 커플은 여기서 연결을 끝낸다.
- **훈련소**: 입대 전에 연결하지 못했어도, 군인이 주말 휴대폰 시간에 앱을 설치하고 링크 한 번으로 연결할 수 있다.
- **혼자 모드(출시 범위에 포함)**: 상대가 아직 연결하지 않았어도 앱을 쓸 수 있다. 입대 전에 연결하지 못한 커플이 첫 주말까지 쓰는 다리 역할이다.
  - 전역일 · D-day 계산을 혼자서도 본다.
  - 곰신이 쓴 편지는 내 폰에 쌓아 둔다. 연결하는 순간 암호화해서 한꺼번에 전달한다("훈련소 동안 쓴 편지 N통 도착").
  - 연결 전에는 상대 키가 없으므로, 쌓아 둔 편지는 내 폰에만 있다.
- **전역**: 완결로 본다. 추억 책은 전역 D-30과 전역일에 집중해서 권하고, 평소에는 추억 탭에서 언제든 살 수 있다. 기념일마다 권하지 않는다.
- **보관 모드**: 기능을 잠그지 않는다. 홈의 주인공만 D-day에서 "함께 견딘 N일"과 추억 책으로 바꾼다.
- **이별**: 각자 자기 사본을 가진다. 보낸 편지는 받은 사람 것이다(손편지 원칙). 약관과 해제 화면에 명시한다.

## 4. 연결과 보안

| 상황 | 결정 |
|---|---|
| 첫 연결 | **초대 링크 한 번**(카카오톡 공유)으로 연결. SAS 숫자 비교는 없다 |
| 기기 교체 · 다시 연결 | 하나의 흐름으로 합친다. 새 폰에서 로그인하면 상대에게 "새 폰 맞나요?" 알림 → 상대가 승인하면 새 폰이 **상대 폰에서** 데이터를 받는다. 코드 입력과 숫자 비교(SAS)는 없다(상대가 전화로 확인한다고 본다) |
| 옛 폰 알림 | 옛 폰이 켜져 있으면 "새 폰에서 로그인했어요" 알림. 내가 한 게 아니면 거기서 막는다 |
| 연속 교체 | 24시간 안의 두 번째 교체 요청은 자동 승인하지 않는다(기존 규칙 유지) |
| 위치 · 군 보안 | 위치 기능은 넣지 않는다. 별도 보안 안내는 하지 않는다 |
| 분석 이벤트 | 정해진 이벤트만 기록(`BizEvent` sealed 구조 유지). **사용자가 입력한 글자는 넣지 않는다**(화면 이름 · 선택지 · 숫자만). 마스킹은 만들지 않는다. 코드 리뷰 기준과 개인정보처리방침에 적는다 |

감수하는 위험: 첫 연결 순간에는 "서버가 키를 바꿔치기하지 않는다"고 믿어야 한다. 연결된 뒤의 대화는 그대로 E2EE다. 이 앱의 실제 위협은 국가 수준 공격자가 아니라 "폰을 남이 보는 것"이다.

## 5. 데이터와 비용

데이터 원본은 **두 사람의 폰**에 있다. 서버는 중계만 한다(동기화 메시지는 TTL로 삭제, 첨부는 받는 즉시 삭제 · Storage 32일 수명주기). **서버 백업은 무료 · 평생 모두 없다**(2026-10-28 결정). 시간이 갈수록 쌓이는 서버 비용이 없다.

| 항목 | 결정 |
|---|---|
| 서버 백업 | **없음**(무료 · 평생 모두). 복구 코드 · 백업 복원 화면 · 백업 보관 기간 함수 · 백업 저장소를 없앤다 |
| 폰 분실 · 교체 | 상대 승인 후 **상대 폰에서** 공유 데이터 + 사진 · 그림 원본을 다시 받는다 |
| 복구하지 않는 것 | 기기 설정 · 임시저장 편지 · 현재 상태 |
| 두 폰을 모두 잃으면 | 되찾을 수 없다. "기기 바꾸기 · 복구" 화면에 한 줄로 알린다 |
| 내 기록 내보내기(ZIP) | 폰 밖에 남는 유일한 사본. "기기 바꾸기 · 복구" 화면에 두고, 연결 해제 · 탈퇴 직전에 권하고, 3개월마다 알림(끌 수 있음). 법적 의무는 없다(본인전송 의무는 대형 사업자만) |

- 공유 데이터: 편지 · 일정(메모 · 그날의 한 줄) · 휴가 · 기념일 · 프로필 · 보고싶어 · 읽음 표시 · 사진 · 그림.
- 남는 비용: 고정비는 Apple 개발자 연 $99 · Google Play $25(1회) · 도메인 정도. 변동비는 Firestore 중계 쓰기 · Storage 첨부 중계(가장 큼) · Functions 호출 · 문의 메일 · RevenueCat(월 $2,500 초과 시 1%). 모두 지금 오가는 양에만 비례한다.

## 6. 수익

구독 없이 **일회성 결제만**. 복무 기간이 정해진 관계라 월 구독은 맞지 않는다.

| 상품 | 가격 | 내용 |
|---|---|---|
| 꽃신 평생 | 7,900원 | 광고 제거 · 글꼴 7종 · 편지지 5종 · 펜 · 색 · 위젯 꾸미기. **연결된 상대도 함께** |
| 추억 책 PDF | 5,900원 | 화면용 + 인쇄용 PDF. 둘 중 한 명이 사면 둘 다 |
| 스티커 | 무료 | 팔지 않는다 |

- 실물 인쇄 책은 하지 않는다(PDF만). 전역 시즌 구매 데이터로 수요가 보이면 다시 검토.
- **광고**: 캘린더 · 휴가 · 설정 화면에만. 편지 · 그림 · 추억 · 홈 화면에는 절대 넣지 않는다. 꽃신 평생이면 숨긴다.

## 7. 사용자 모으기

- 채널: **곰신 커뮤니티** + **유료 광고** + **앱스토어 검색**(군인이 "전역일 계산기"로 찾는 길). 노출 시점은 **영장이 나온 뒤 ~ 입대 전**(설치하는 시점)에 맞춘다.
- 앱스토어: 스크린샷 첫 장에 **두 테마를 나란히**("같은 편지, 각자의 화면"). 검색어는 "전역일 계산기 · D-day · 군인"과 "곰신 · 커플 앱 · 편지"를 모두 넣는다.
- 광고 소재: 곰신 커뮤니티 · SNS에는 곰신 테마, "전역일 계산기" 검색 광고에는 군인 테마. 아이콘은 어느 테마에도 치우치지 않는 하나.
- 홍보 각도: "영장 나오면 둘이 같이 까는 앱 · 입대 전 필수 준비물" + 혼자 모드의 "편지가 한꺼번에 도착" 순간(공유 화면 → 바이럴).
- 성과 기준: 설치 수가 아니라 **연결까지 완료한 커플당 획득 비용**.
- 출시 뒤 지표: 설치 후 7일 안 연결 전 이탈 비율, 그중 상대가 훈련소 기간이던 비율(입대일로 계산).

## 8. 제품 결정 (디자인 점검에서 나온 기능 변경)

화면 · 시각 규칙은 [design.md](design.md)에 있다. 여기에는 동작이 바뀌는 결정만 둔다.

로그인 · 초대 · 연결:
- 소셜 로그인 카카오 · Apple · Google. Apple 로그인은 Android에도 노출(iOS 심사 4.8).
- 초대 링크: 카카오톡 피드 템플릿 공유 + OG 미리보기. 이름 외 개인 정보는 넣지 않는다.
- 초대를 보낸 뒤 바로 홈(혼자 모드 · "기다리는 중" 표시 · 링크 다시 보내기)으로. 상대가 수락하면 푸시 + 앱을 열 때 연결 모달. 혼자 쓴 편지가 많으면 "편지 N통 보내는 중" 진행 화면.
- 만료된 링크를 연 사람에게는 "이 초대 링크는 만료됐어요" + "내가 초대 링크 보내기".

편지 · 그림 · 그날의 한 줄:
- 임시저장: 편지함 맨 위 "쓰던 편지 N통" 줄 + 편지 쓰기를 열 때 "이어 쓸까요?" 시트. 임시저장은 기기에만 있고 복구하지 않는다.
- 편지 탭 쓰기 버튼 → "편지 쓰기 / 그림 그리기" 메뉴(그림만 보내면 그림 한 장짜리 편지). 받은 그림에서 "그림으로 답장"은 바로 그림판.
- 예약 보내기: 캘린더에서 날짜를 고르고 시간을 넣는다.
- "만남 남기기" → **"그날의 한 줄"**. 두 사람이 실제로 만난 날(면회 · 휴가 · 외박)에 한 줄(40자) + 사진을 남긴다. 그 일정이 끝난 다음 날 푸시 + 홈 카드, 일정 상세 버튼, 추억 탭 위쪽 버튼.

캘린더 · 휴가:
- 휴가는 **하나의 풀**("남은 휴가 18일 / 전체 32일"). 받은 휴가(정기 · 포상 등)는 출처 내역으로만 보이고, 쓸 때는 기간만 고르면 전체에서 빠진다(출처를 고르지 않는다). 데이터 모델(`Event.leaveGrantId`) 변경 필요.
- 입대일 · 군종을 넣으면 정기휴가 자동(육군 · 해병 24 · 해군 27 · 공군 28일). "휴가 없음" 빈 상태는 없다.
- 휴가 관리는 설정이 아니라 **캘린더 탭 위쪽**에 둔다.
- 일정 추가에서 휴가를 고르는 것과 휴가 사용 등록은 같은 동작이다. 기간을 고르면 "5일 사용 · 남은 휴가 13일"을 보여 준다.
- 기념일은 "매년 반복"(기본 켬)을 고를 수 있다.

추억 책:
- 권유는 홈 배너가 아니라 D-30 · 전역일에 **가운데 팝업**(표지 미리보기 + "다시 보지 않기 | 닫기"). 홈은 건드리지 않는다.
- 표지 2종(꽃신 편지지 · 군사우편) 중 산 사람이 고른다. 속지: 표지 · 요약 · 한 달(왼쪽 달력 + 사진, 오른쪽 편지 세 통) · 마지막 장.

설정:
- 백업 항목은 "기기 바꾸기 · 복구"가 된다(복구 방법 안내 + 내 기록 내보내기).
- 휴가 관리는 설정에서 빠진다.

출시 뒤로: 그림판 필압 · 손바닥 터치 무시, 보관 모드 홈 화면(첫 사용자 전역까지 18개월 이상 남음), 실물 책.
